# Execution evidence (text only)

Everything in this folder is real output from the deployed build in
`https://fevm-cs-genie-research.cloud.databricks.com` (catalog `cs_genie_research_catalog.ad_sales`).
Files `01`–`09` come from `capture_evidence.py`, which queries the live workspace (warehouse SQL,
pipeline event log, MLflow, Lakebase Postgres, Genie Conversation API, Lakeview API, and the
deployed app's HTTP API) and writes the results as markdown. Re-run it with:

```bash
.venv/bin/python -I evidence/capture_evidence.py            # all stages
.venv/bin/python -I evidence/capture_evidence.py genie app  # selected stages
```
